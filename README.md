> **Onboardify** es una aplicación web interactiva diseñada para organizar, registrar y optimizar el proceso de aprendizaje al ingresar a un nuevo puesto de trabajo. Permite centralizar apuntes, tarjetas de repaso, control de horas y dudas pendientes, separando toda la información por empresa y asegurando la persistencia de los datos directamente en el navegador.

## ✨ Características Principales

* 🏢 **Gestión Multiusuario / Multiempresa:** Organización independiente de la información para diferentes puestos o empresas de manera clara y ordenada.
* 📝 **Módulo de Apuntes:** Espacio dedicado para documentar procesos, instrucciones y notas clave durante los primeros días de trabajo.
* ⭐ **Tarjetas de Repaso:** Sistema de tarjetas interactivas para afianzar conceptos clave y acelerar la curva de aprendizaje técnico u operativo.
* ⏱️ **Control de Horas:** Registro y seguimiento del tiempo dedicado a capacitaciones, prácticas o tareas asignadas.
* 💭 **Registro de Dudas:** Apartado especial para anotar preguntas e inquietudes apenas aparezcan, permitiendo agruparlas y consultarlas todas juntas en el momento adecuado.
* 🎨 **Personalización y Temas:** Opciones de visualización adaptadas con el estilo estético kawaii característico para una experiencia agradable y fluida.
* 💾 **Persistencia Local:** Todos los apuntes, repasos y registros se guardan de forma segura directamente en el almacenamiento del navegador (`localStorage`).
* 📄 **Exportación de Datos:** Funciones rápidas para exportar la información por empresa individual o realizar una copia de respaldo completa de todo el contenido.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5 semántico, CSS3 moderno, JavaScript (Vanilla ES6+).
* **Almacenamiento:** LocalStorage API para la persistencia de datos en el navegador del usuario.
* **Entorno & Deploy:** Git, GitHub Pages.

---

### 🎯 Objetivo del proyecto

El objetivo principal es ofrecer una solución práctica y ligera para enfrentar con éxito los primeros días en un nuevo empleo, optimizando la asimilación de procesos corporativos y estructurando el conocimiento técnico mediante herramientas enfocadas en la productividad y la experiencia de usuario.
